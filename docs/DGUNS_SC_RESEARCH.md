# 毁灭枪手 Σ：全资源提取与 SC 设计建议

## 本轮结论

适合把终末地炮塔、轻工业和毁灭枪手机甲接成同一条路线：**基地生产/充电 → 玩家驾驶机甲出击 → 敌方据点/首领产出研究材料 → 解锁下一代机体**。炮塔负责持续守线，驾驶机甲负责机动与主动处理威胁；不能把后期机甲做成免费无限弹药、自动碾过所有其他 Mod 的载具。

本轮只提取、分析、做中文索引和候选表。没有修改 `Mod/`、现有战斗参数、正式安装、世界或模型工程，没有发布新版 scmod。

## 3. 原作数值：为什么不能照搬

原作主角基础HP从水星6000到候150000，基础攻击1000–20000，EP100000–900000、装备槽12–64。角色等级、机体强化、装备继续叠加。它们与SC的“归一化Health/Hitpoints + AttackResilience”不是同一套量纲。

重要字段已做两种交叉验证：32位/64位表的标量相等；匹配ELF的AArch64指令独立反汇编确认敌HP `+8`、攻击 `+6`，玩家HP `+12`、EP `+16`、攻击 `+8`。不是把一堆浮点数凭大小猜成速度/伤害。

原生伤害路径 `set_dmg` 的主要形式：

`攻击基数 = ((机体攻击 + 附加值) × 攻击配置百分比 + 99) / 100`

再扣目标对应通道的抗性。普通通道与界面对应冲击、爆炸、电击；武器并非只看装备名字。特殊DEV分支还会查看恶魔标志，有×5/×70的内部处理，UI另有×5/×10说明；这些位于不同组合层，不能直接搬一个内部常数来宣布最终倍率。

### 敌人和Boss不能只读一列HP

- 普通双管兵基础800起，后续型号/变体1800、3800、5000；重炮/导弹兵还能到9000。
- 剑装Boss基础6000/9000/12000；指挥人形2500–10000；鸟形重装17000；重炮车20000。
- 生成函数 `set_1corp` 会按任务、层数、难度、等级再算HP与攻击，Boss还会获得额外加成。表内14000的恶魔外形并不代表特殊事件里只有14000血。
- `set_king_boss` 特殊事件基础式是 `60000 + 20000×等级`，等级≥8、≥21还分别追加分段增量。RD17事件路径实际写入该HP，并让三类抗性中两类达到90%、一类维持弱点。它是“找弱点+持续遭遇”，不是独立一台普通血牛。
- 首领有阶段/死亡过程，例如RD13在致死前会先保留1HP进入动作。该过程不能通过套SC通用血量与立即销毁模型来假装还原。

## 4. 与本机其他Mod放在一起的设计

延续上一轮 `INDUSTRY_BALANCE_RESEARCH.md` 的精确包证据：尸鬼普通25–100、重型260–1000（还有脚本变化）；恶灵警笛头1024/移速10，芬里尔1600/移速7，Smolder3200/飞速15；CS敌兵60或180；BF载具模板650–2000。

目标不是“越晚解锁就所有属性更高”，而是划分生存用途：

- **炮塔**：材料便宜、自动防守、离不开供电与位置；固定阵地单位投入火力高。
- **主角机甲**：玩家主动操作，有补给/维修成本，解决侧翼、空中、野外探索和据点战。停放后仍是独立载具，不替换玩家模型。
- **普通敌兵**：给玩家和入门塔留可控反应时间，包含射击、导弹、炮击、无人机，不能全换皮用同一个近距离追击AI。
- **精英同型机**：更好的武器/装甲/行为，数量少；不把20台玩家机全变成自然刷新的敌人。
- **Boss/恶魔事件**：预警、阶段、明确战区、弱点与奖励；默认玩家主动触发，不无预警炸已有基地。

### 兼容性前提

1. 先解决上一轮发现的 `Bird`/`LandOther` 与自定义AI漏敌。机甲必须有独立阵营与所有者；同一模型可敌可友。第三方Robot、无人载具、玩家僚机不能仅凭Category自动判敌。
2. 不能绕过恶灵的单次限伤（警笛头1.2%、芬里尔5%）或尸鬼的伤害预算。高能炮仍可能不如连续命中武器打这些Boss。模型/武器外观不授予“无视别人的钩子”。
3. 敌方能否攻击 `ComponentDamage` 机甲也需测。很多AI只找生物，可能把无驾驶者机甲当空气；应做适配，不用给载具无限血掩盖。
4. 未知第三方攻击不能根据特效颜色猜冲击/爆炸/电击。对我们自己的武器用明确类型；未知攻击先用保守中性处理，只在版本可核对的桥接层映射，避免双重护甲减免。
5. 飞行只在加载区、低空与地形安全范围内工作。先实现悬浮/短距跃迁，不直接给无限升空穿山。驾驶者上下车安全、碰撞、多人归属、存读档都必须保留。

### 现有样例应先平衡哪儿

现有机甲样例步枪65/0.16秒，理论瞬时406.25攻击力/秒；激光90/0.4=225，火炮180/1.4≈129，导弹120/1=120，榴弹130/1.2≈108。步枪热量会限制持续射速，但当前不耗库存弹药；五种弹药仍主要共用直接射线结算及不同表现，不能把它当已经具备真正制导/溅射的完整武器系统。

首轮建议以武器本身定伤害，再乘有限的机体火控倍率：

| 武器 | 建议基础攻击 | 周期/射程 | 运行成本与区别 |
|---|---:|---|---|
| 步枪 | 22/发 | 0.18秒，40格；24发匣、2秒装填 | 瞬时约122 DPS；以 N×间隔+装填的预算口径约83.5持续DPS；实耗弹药 |
| 导弹 | 140/枚 | 2秒/枚，48格 | 真正追踪、可被墙挡；最多2枚同时飞行不是每次白送2枚 |
| 火炮 | 360/发 | 3.5秒，48格，盲区6格 | 约103单目标DPS，半径3群伤；高单发、弹壳/装填代价 |
| 激光 | 240/次总量 | 0.5秒充能、0.8秒输出，起射周期3秒、36格 | 约80平均DPS，140DU/次；逐段伤害不是240/每帧 |
| 榴弹 | 220/枚 | 3秒、24格、半径3.5 | 近距抛物线清杂，弹道/友军安全检查 |
| 近战 | 90/击 | 0.9秒、3.5格接触 | 能源15DU/次；挥空也有代价，剑系可另增专精倍率 |

机甲能源还需要待机/行走/冲刺耗能。不要让枪械完全免费，也不要让物理弹同时承担过高电费与弹费。能源/弹药/热量三个预算分别解释清楚，不只用一个“热条”替代全部成本。

### 与上一轮炮塔搭配的预算例子

候选暴雨一座162.5 DPS、哨戒一座480/4.5、迫击炮一座640/7，直伤预算约360.6 DPS。若**假设**命中率70%、有效输出时间65%、平均护甲后保留80%，约131.3 DPS，对12000HP约91秒连续预算。这里只是规划90秒级事件的例子，不包含首发、离散弹次、盲区、弹道、地形、断电、维修和玩家输出，**不是实测击杀时间**。

若同时有10座高级塔，Boss自然会更快倒下。建议用有限增援、弹药消耗、侧翼与可应对的供电压力制造挑战，而非暗中无限缩放血量、随时无敌或强拆玩家主基地。所有破坏地形/攻击工业设施的事件选项应默认保守、明确提示并由玩家启用。

## 7. 与工业材料和基地经济衔接

接着上一轮做，不重新发明另一套孤立材料：

1. 钢板/铜线/基础电路/机壳 → 水星与基础枪弹、简易维修架。
2. 伺服/电容/强化机壳/储能电池 → 复仇女神、轩辕十四、阿瓦隆等；机库能充电、装弹、维修。
3. 高级板/功率模块/复合装甲/光学与制导件 → 专精机体、装配流水线与高级炮塔。
4. 首领研究数据+通用工业材料 → 终局原型。研究数据来自成功应对事件，不让玩家为了每一块维修钢板被迫重刷Boss。

具体原则：

- 一个机体是底盘+动力+控制核心+武器/防护模块，不是整件套数值无限叠。4–8槽只是装备种类上限，还要有功耗、重量和散热限制。
- 旧机可升级或拆回核心，损坏时保留残骸和可回收库存；避免现有样例8秒清掉机甲后让所有生产投入消失。适配旧存档前要先定迁移规则。
- 普通敌兵掉钢料/电子废料/少量弹药，精英掉可修复伺服/控制板，Boss掉有限研究数据。设置研究保底，重复Boss给材料，不复制整台满配机甲。
- 同模不同参数机体不应都做成完全独立的重复配方：阔刃剑→刀锋、天狼星→克雷斯塔等可在机库选择升级包；保留型号、原名及中文名。
- 四种涂装只影响外观，不能四份同模资源每帧重载；网格缓存与贴图切换分离。
- 工业时代仍是可选适配：稳定材料ID/标签映射，明确能量换算；不把其程序集、美术或原作者内测包分发出去。
