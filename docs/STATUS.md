### 根因

- **文字穿墙**：世界里的所有文字（反应名字、伤害数字、首领名字和失衡字样、核心那行字、断电字样）共用一个文字批次（`labelBatch`，粒子渲染器的 FontBatch），
  0.15.0 起用 `DepthStencilState.None`——不做深度测试，什么都挡不住它，只受各自的显示距离限制。图标、耐久条、首领血条在 0.18.2 挪到模组自己的渲染器时就是深度测试的。
- **硬控几乎永久**（详见 `docs/COMBAT_DESIGN.md` §12.1）：① 所有炮塔每帧减两次冷却（`ComponentMDUnit.Update` 一次、`MDTowerBrain.Update` 又一次，0.4.0 起），
  实际射速是表上的两倍：电磁脉冲 Ⅲ 的 2.5 秒瘫痪实际每 2.4 秒补一次，一座就能永久瘫痪；② 普通敌人的眩晕没有任何递减和免疫，几座塔、几种反应各算各的；
  ③ 冻结和眩晕不共享，敌人瘫着时冻结只是换个图标，冰冻减速在速度 0 时毫无作用。射速这一条**没改**（会把所有炮塔的输出减半），等用户定。

### 改法

- 文字批次（`MDElements.cs` `Labels()`）改成 `DepthStencilState.DepthRead`（只读深度、不写），层 `LabelLayer = 6`：排在范围圈（3）、核心光柱（5）之后；
  图标和耐久条在整个粒子渲染器之前就画完（`FlushOverlay`），所以文字总是叠在它们上面。仍用渲染器的无雾着色器（0.18.2 的“不受雾影响”不变）。
- `MDTowerWorld.InFront`：从眼睛到提示的连线如果先穿过目标自己的碰撞盒（四周加 0.3 米 + 尺寸的 10 %），就把提示画在进入点前面一点，按同样比例缩小——
  屏幕上位置、大小完全不变，只是深度在目标身体前面。用于伤害数字、反应名字、敌人状态图标、首领血条和名字（整组一起）、核心那行字和能量条、断电字样。
  墙、山、其他生物仍然挡住它（它们不在目标的盒子里）。
- 硬控：`MDControl.cs` `NormalHard`（一段最长 `NormalHardCap` 3 秒，之后免疫 `NormalHardImmune` 2 秒）；`Stun` / `Freeze` 已经都经过 `Control`，所以塔、反应、液氮都在里面；
  `HardResisting` 给选目标用；`MDTowerBrain.FindTarget` 对有 `stun` / `freeze` 的塔把被控 / 免疫中的敌人排到后面。首领的分支不动。
- `towers.json`：冰冻塔 Ⅰ `power` 0 → 15；液氮塔 `power` 0 → 40、`zonePower` 0 → 16（冰面每 0.5 秒一跳，每跳 = zonePower × 0.5 = 8）；两座的简介改了。

### 更新说明（给玩家）

1. **声波塔、电磁脉冲命中会留下“带电”**：全向声波塔的波面、电磁脉冲 Ⅰ–Ⅲ 的脉冲弹（直接命中和爆开范围）打到敌人，和其他电系塔一样挂上“带电”状态、
   头顶显示电元素图标，能和其他元素起反应（例如敌人身上有“灼烧”时触发“过载”）。它们本身仍然没有伤害，所以平时不出伤害数字；
   反应如果带伤害（热冲击），照常出数字。
2. **同类问题一起修了**：液氮塔（炮弹和冰雾）、冰冻塔 Ⅰ 也是 0 伤害，以前只冻结 / 减速、不留“冰寒”，现在会留；机甲的榴弹、导弹、炮弹按**发射时**的
   武器和弹药算元素（以前按落地时手上选的武器，飞行中切到激光就变成电）；机甲近战固定是动能（或装填的元素弹），以前跟着当前选的武器变（选导弹时是爆炸）。
3. **创造模式物品栏**：“机甲防线”栏目移到“武器”后面（以前在所有原版栏目最后）；其他栏目顺序不变，合成表（百科）的分类顺序一样。

### 根因

元素只在 `MDTowerBrain.Hit` 里经 `MDTowerWorld.Elemental` 附加。`Hit` 开头 `power <= 0` 直接返回，而声波塔（0.18.0 改成 wave）、电磁脉冲（orb）、
液氮、冰冻塔 Ⅰ 的 `attack.power` 都是 0；声波的 `WaveTick` 和旧的 `Pulse` 还自己判断 `if(a.power>0)` 才调用 `Hit`。所以这几种塔只眩晕 / 冻结 / 减速，
从来没走元素逻辑（不是 0.18.0 才坏的：0.15.0 加元素以来声波、电磁脉冲就没有元素，0.18.0 改成射出去以后玩家才看清楚）。
改法：同一个入口——`Hit` 对“会留状态的元素”（热、冷、电、腐蚀）的 0 伤害命中也走 `Elemental`（抗性、状态、二元 / 三元反应、冷却全部照旧），
结果仍是 0 就不发攻击（不出伤害数字、不算仇恨）；动能 / 爆炸的 0 伤害命中（激流塔）照旧什么都不做（它们不留状态，只会白白消耗目标身上的状态）。
`WaveTick`、`Pulse`、喷射 `AreaTick` 去掉 `power>0` 判断，交给 `Hit`。实验室开关 `MDTowerBrain.StatusWithoutDamage=false` 退回 0.18.0。
