# 终末地防御塔 · 0.4.x

19 种终末地防御塔，全部用 `E:/projects/endfield-turret-model` 的自制方块模型和自绘原色贴图
（铳械塔三座 = `v1/`，其余 16 种 = `batch2_v2/`）。原始游戏模型、贴图、特效不进包；
音效是终末地原始音频（Wwise 事件混成 OGG）。旧存档里的机甲、敌兵保留。

## 0.4.0 相对 0.3.1 改了什么，为什么

| 0.3.1 的问题 | 根因（已用工具证实） | 0.4.0 的做法 |
|---|---|---|
| 贴图“变色”、像重叠面闪烁 | 方块模型里有大量相距 0.1～0.5 mm 的同向重叠面（倒角板、贴片、圆环分片；Blender 近景看不出）。0.3.1 只合并了“同一骨骼内、距离 0.01 mm 以内”的面：三座铳械塔仍有约 8,500 对相距 <1 mm、约 5,000 对 1～3 mm 的重叠面，外加 114 对底座/转台之间完全共面的面。游戏里深度精度不够，这些面互相抢着显示 | 按刚体部件做隐藏面处理：被同部件实体填满的面整块删除；与同向面相距 6 mm 以内的重叠区域裁掉下面那块（完全共面或微倾斜相交时保留较小的贴片）；不同部件之间仍重合的面把运动部件推出 7 mm |
| 有的地方贴图发黑 | 贴图坐标没有问题（三座塔全部 5 万多个三角形抽样，没有一个取到空白或纯黑像素）。推断原因：0.3.1 自绘时关闭了背面剔除、光照只乘天空亮度，深灰面在暗处接近黑色；再加上重叠面互相抢深度，深色的面会在浅色面上闪出来 | 走游戏原生模型渲染（世界光照、雾、阴影、背面剔除），见下 |
| 炮管转动时穿模 | 0.3.1 把终末地原始 VAT 动画直接套到自制炮管上：原动画每次开火让左右炮管绕自身轴转约 180°，而自制炮管不是绕那根轴对称的圆柱，转起来扫过炮头。0.3.1 的检查只看炮口一个点有没有偏离，没查整根炮管扫过的体积 | 不再套原动画。每种塔按自己的几何做动作：炮管沿轴后坐；俯仰范围由离线碰撞检查算出（偏航每 10°、俯仰每 2°，运动部件与静止部件不得新增超过 1.2 cm 的穿插；圆轴在轴孔里转动不计），超出范围就夹住；迫击炮、序章炮塔俯仰固定（支架、液压杆是刚性的），只转偏航 |
| 特效不满意 | 0.3.1 把终末地 Unity 粒子采样后用一个个三角形重放，很多模块（扭曲、软粒子、拖尾）没移植，看起来脏、散 | 自制像素风特效（与方块模型同一风格），按塔的攻击方式分别设计：枪口焰、能量弹拖尾、火焰/酸液/毒雾/冰晶爆炸、激光充能+光束、闪电弹射、激流、火焰喷射、震荡波、治疗 |
| 装进游戏很卡 | ① 物品栏图标每帧把整座塔（1.5～1.9 万个三角形）重新变换上传，快捷栏放几个就卡；② 场景里每座塔每帧在 CPU 上逐顶点变换并重新上传整座模型；③ 每座塔模型是 8～11 MB 的 JSON，特效库 39 MB JSON | ① 图标改成预渲染贴图（每格 2 个三角形）；② 模型改成 glTF 交给游戏的实例化渲染，几何一次性上传显存，每帧只更新几根骨骼矩阵；③ 资源改成二进制 glb，包体 10.7 MB |

## 结构

- `tools/towers.json`：每种塔的来源、可动部件（按方块标签切出炮管等）、玩法参数、特效颜色、音效。
- `tools/build_tower_assets.py`：geo.json + 贴图 → `Mod/Assets/Towers/<id>/model.glb`、`atlas.png`，以及运行时表
  `Mod/Assets/Towers/towers.json`（骨骼、炮口、俯仰范围、占地）。隐藏面处理和碰撞检查都在这里。
- `tools/make_fx_atlas.py`：特效像素图集 `Towers/fx.png`。`tools/render_tower_icons.py`：Blender 渲染物品图标。
- `tools/extract_tower_audio.py`：其余 16 种塔的终末地原始音效（技能数据里的事件名 + 约定事件名，只保留银行里真实存在的）。
- `Mod/MDTowers.cs`：定义加载、骨骼姿态、`ComponentMDTowerModel`（游戏原生模型组件，按瞄准和后坐设置骨骼）。
- `Mod/MDTowerBrain.cs`：索敌、瞄准、各攻击方式。`Mod/MDTowerFx.cs`：特效、炮弹、持续区域、减速/眩晕/破甲。

## 重新生成与验证

```
python tools/build_tower_assets.py            # 约 12 分钟
python tools/make_fx_atlas.py
blender -b --factory-startup --python tools/render_tower_icons.py --
python tools/extract_tower_audio.py           # 读取已安装的终末地（只读）
python tools/prepare_database.py
python tools/package.py                       # -> dist/MechDefense-<版本>.scmod
python tools/run_isolated.py lab --mode all   # 隔离运行时：截图 + 帧时间，结果 local/runtime-lab
python tools/run_isolated.py perf --package dist/MechDefense-0.3.1.scmod --label old   # 同场景性能对比
```

隔离运行时在 `local/runtime-*`，不碰正式游戏目录和存档。

## 边界

- 玩法：射程、攻击间隔、最小射程、范围形状（圆形 / 7×3 矩形）取自 FactoryBattleTable；伤害按
  终末地攻击力的 0.45 次方换算到生存战争的生物抗性量级（狼 20、熊 70、犀牛 150），不是原数值。
- 动作是按自制几何设计的程序动作（转台偏航、俯仰、炮管后坐），不是终末地原始动画。
- 音效是原始音频的确定性混音（随机容器取一个子项，叠加层全部混合，峰值限幅），不是 Wwise 实时播放；
  序章炮塔没有专属音效，借用重锤迫击炮的开火声和游戏自带爆炸声。
- 特效全部自制，不是终末地原特效。

## 验证结果（2026-10-09）

在你的游戏程序（`D:/下载/[Windows]SurvivalcraftAPI_1.9.3.1`）的隔离副本里测试，不碰原目录、模组和存档。

- 重叠面（静止姿态下同向、相距 4 mm 以内、重叠超过 1 mm² 的面对，`tools/check_tower_overlaps.py`）：
  0.3.1 三座铳械塔各约 13,000 对（<1 mm 约 8,500 对、1～3 mm 约 5,000 对）外加 114 对完全共面；
  0.4.0 有 18 种为 0，重锤迫击炮剩 2 对（各 0.4 cm²）。
- 三角形数：铳械塔 0.3.1 为 14,778 / 19,263 / 17,778，0.4.0 为 10,974 / 12,546 / 12,479；其余 16 种 6,916～39,468。
- 帧时间（同一场景：30 座铳械塔在视野内，快捷栏放 9 个塔物品，关垂直同步，`tools/run_isolated.py perf`）：
  0.3.1 每帧 70.3 ms（约 14 FPS），0.4.0 每帧 0.66 ms；只放快捷栏物品时 0.3.1 为 7.06 ms，0.4.0 为 0.73 ms。
- 游戏内（`tools/run_isolated.py lab`）：19 种塔全部加载、显示、开火并命中目标；医疗塔把玩家生命从 0.7 治到满；
  转台每 45° 和俯仰两端的关节近景已截图检查；带上你的 Neorxna 1.4 副本时 19 种塔都显示正确中文名。
- 运动检查：所有带转台的塔偏航 360° 无新增穿插；炮管后坐无新增穿插。

没有验证：在你装了 30 多个其他模组的正式游戏里实际游玩；旧存档里 0.3.1 炮塔升级后的表现（模板名、骨骼不变，
按设计会换成新模型，但没在你的存档上试）。
