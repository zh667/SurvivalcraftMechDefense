## 设计

### A. 击退、硬直和控制（第 3、8 条）
- 炮塔打机兵：不再有引擎的受击硬直（0.2 秒）和击退。例外：塔定义里 `stagger: true` 的单发重炮——加农炮 Ⅰ～Ⅲ、榴弹塔、
  高爆榴弹塔、序章炮塔、重锤迫击炮、哨戒塔。玩家和机甲的攻击照旧。首领、无人机本来就没有。
- 控制（电磁脉冲、全向声波的眩晕，液氮的冻结，以及元素反应里的“过载”）期间机兵**不能开火**：正在蓄力或连发的一轮也打断。
  不递减（用户：“被控效果不用递减”）。首领不受控制（照旧）。
- 冰冻塔 Ⅰ～Ⅲ 去掉推力（它们靠伤害把机兵推出自己的射程，减速只剩 21～23 %）。激流塔保留推力，基准测试加测推开的距离。

### B. 伤害类型、元素状态和反应（第 4 条）
六种伤害，每座塔一种（`towers.json` 的 `element`），图鉴、物品说明、炮塔信息里都显示图标和名字：

| 伤害 | 颜色 | 炮塔 |
|---|---|---|
| 动能 | 灰白 | 铳械塔三阶、转轮机枪三阶、防空炮三阶、哨戒塔、激流塔 |
| 爆炸 | 橙 | 榴弹塔、高爆榴弹塔、序章炮塔、重锤迫击炮、导弹塔三阶、加农炮三阶 |
| 热 | 红 | 火焰塔三阶、AF1“熔甲者”；燃烧（着火）也算热 |
| 冷 | 青 | 液氮塔、冰冻塔三阶 |
| 电 | 紫 | 射线塔、高能射线塔、电涌塔、甲二型“电荷”、磁暴线圈三阶、电磁脉冲三阶、全向声波塔 |
| 腐蚀 | 绿 | “酸洗”MK-Ⅰ、“毒沼”MK-Ⅰ |

- 热、冷、电、腐蚀命中时给目标挂上对应的**元素状态**（灼烧 / 冰寒 / 带电 / 腐蚀），持续 6 秒，再次命中刷新。动能、爆炸不挂状态，
  但能和已有的状态反应。
- 机兵头顶显示**状态图标**：元素状态，以及减速、冻结、瘫痪（眩晕）、破甲、中毒；32 米内可见，最多一排 5 个。
- **反应**（目标身上已有状态 + 另一种元素命中）：

| 组合 | 反应 | 效果 |
|---|---|---|
| 热 + 冷 | 热冲击 | 这一击额外 +100 %，并扣目标 3 % 最大耐久；两种状态都消掉 |
| 热 + 电 | 过载 | 3 米爆炸，周围敌人受这一击 60 % 的伤害；目标瘫痪 1.5 秒（停火） |
| 热 + 腐蚀 | 腐燃 | 着火 4 秒，破甲（受伤 +25 %）6 秒 |
| 冷 + 电 | 脆化 | 6 秒内受到的动能、爆炸伤害 +35 % |
| 冷 + 腐蚀 | 冻蚀 | 减速到 40 % 共 4 秒，破甲 +15 % 6 秒 |
| 电 + 腐蚀 | 电解 | 电弧跳到附近 3 个敌人，各受这一击 50 %，并给它们挂上腐蚀 |
| 爆炸 + 任一状态 | 扩散 | 把这种状态传给 4 米内的敌人（不额外加伤害） |
| 动能 + 冰寒或冻结 | 碎冰 | 这一击 +60 %，冰寒和冻结消掉 |

- 冷却：同一个目标发生任何反应后 1.5 秒内不再反应；同一种反应在同一个目标上 6 秒一次。首领可以反应，但瘫痪对首领无效，
  “扣最大耐久”对首领按装甲阶段算。
- 反应时：目标处一圈两种元素颜色的光环 + 闪光，头顶飘出反应名（带图标）；粒子数量受“特效数量”设置控制。
- 每种敌人一张抗性表（×0.75～×1.5，图鉴里列出）。模组设置里可以关掉元素反应（状态和抗性照旧）。

### C. 普通敌人（第 1、2 条）
- RD05：被玩家瞄准（准星 3 米内、40 米内）时横移 1.5 秒（4 秒一次）；耐久低于 30 % 后撤 4 秒（一次）。
  阵地附近（离最近的炮塔 30 米内）的玩家在视野里时优先打玩家。
- RD14：正面受伤 ×0.75、背面 ×1.4；炮塔转速 1.6 → 0.9 rad/s，玩家能绕。
- RD07：炮弹落点出红圈；玩家在 12 米内时转身慢。
- RD06：不变（已有锁定预警）。
- RD09 / EN02：附近（24 米）没有炮塔的玩家优先打；阵地附近的玩家同 RD05。
- 维修无人机（新，后期阶段）：用 RD09 的模型换绿色涂装，不开火，给 16 米内受伤的机兵回血（不给首领回），图鉴里写“优先打掉”。

### D. 成长（第 5 条）
- 阶段按“开始天数”（设置里已有）算：开始天数当天起 普通机兵；+3 天 战车、小无人机；+7 天 精英；+14 天 维修无人机。
- 每个阶段机兵耐久和伤害 +10 %，最多 +50 %（每 7 天一个阶段）；设置里加“敌人成长”：关 / 5 % / 10 %（默认）/ 15 %。

### E. 奖励（第 6 条，专属部件不做）
- 掉落按耐久缩放：RD09 少掉残骸、芯片概率高；RD14 多掉。
- 玩家或机甲造成至少 30 % 伤害的击杀：经验和残骸 +50 %；击杀时目标正处在破甲窗口 / 被打断 / 弱点命中过：再加经验。
- 每打破首领一层装甲掉 3～5 个残骸；第一次击败每种首领多掉一份（存档记录，图鉴标“已击败”）。
- 夜袭全部打退：在最近的炮塔旁给一次结算（残骸、经验，按当晚规模）。

### F. 其他（第 7、9 条和“二～五”）
- RD21 耐久系数 1.1；RD08 和目标保持 22 米（大多数塔的射程内），玩家靠近时退到 26 米。
- 图鉴：RD06、RD07 写明射程比一、二阶铳械塔远。
- 实验室补：无人机坠落姿势、RD19 机鼻细缝截图、无人机风扇截图（给用户看）。
- EN02 投弹、机鼻激光；无人机换自己的声音（从已提取的资源里找）。
- STATUS.md 改正 0.13.0、0.14.0 的“未合并”。
- 真手机测试、“机甲放置出来不可见”的手机日志：需要用户。

## 追加（10-30 用户）
- “炮塔对于其他模组生物和原版生物好像还有击退效果（一些没击退效果的炮塔）”：`MDRobots.Unstaggered` 改为对所有生物生效（原来只对我们的机兵），

- “伤害数字显示……海量敌兵要处理得当，不要整得满屏数字，也要注意手机设备性能问题，包括之前的元素反应”：`Mod/MDDamageNumbers.cs`。
  数字读的是最终扣血（装甲阶段、抗性、其他模组的倍率之后），颜色是伤害类型，反应是大字；同一目标 0.35 秒内的伤害合成一个数；
  28 米内才显示；同屏最多 14 / 8 / 4 个（特效数量 完整 / 精简 / 极简），满了先替换最淡、最小的；反应名同屏最多 6 / 4 / 2 个；
  模组设置“伤害数字”可关。文字用游戏自带字体批量绘制，描边只画四个方向。
