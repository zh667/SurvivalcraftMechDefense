## 6 条反馈和做法

1. 防线核心：光柱（远处可见，注意手机性能）；点击核心一键显示 / 隐藏所有防御塔的攻击范围和耐久条，和 0.17.0 的 Z 键状态一致。
   - 光柱：`Mod/MDThreat.cs` `CoreBeam`，渲染器的平面批次（无纹理、无粒子、不受雾影响），每帧 54 个四边形，深度测试（山会挡住）。
   - 点击：`Mod/MDTowerTools.cs` `CoreClick` / `SetAll`，接在右键交互链最后（维修材料仍然是维修）。Z 和核心共用 `Shown` 集合。
   - 耐久条：0.17.0 没有（只有 Neorxna 信息面板的文字），新加 `MDTowerWorld.DrawTowerBars`（`Mod/MDTowerRanges.cs`），跟着 `Shown` 走。
   - 全部显示时只画 96 米内的圈、40 米内的填充（性能）。
2. 迫击炮锁定水下的鱼和地下洞穴里的生物：所有塔的索敌改成“打得到才锁”（`MDTowerBrain.FindTarget` / `Reach`）。
   - 水下（身体顶部在液体里）一律不锁；曲射（所有 shell 类塔）按出膛弹道穿过地形逐段检查（`MDCombat.ArcClear`），落不到目标附近就不锁；
     喷射类和声波 / 电磁脉冲要求中间没有方块；其他直射塔照旧要求视线。每 0.25 秒重新挑，打不到就换目标。
   - 范围伤害（喷射、脉冲）也不再穿过地面、不打水下。
3. 首领和恶魔机甲因元素反应原地罚站：首领控制抗性（`Mod/MDControl.cs`）。减速对首领减半；控制按“段”算，同类控制每段递减一半，段后免疫一段时间；
   硬直（破甲、失衡、RD19 主炮被打断）也走递减，但伤害窗口（破甲 10 秒、失衡 8 秒 ×1.5）不变。普通机兵和精英保持 10-30 的决定（控制要停火，不递减）。
4. 战车卡坑、隔墙开炮：所有地面敌人和敌方机甲。
   - 生成：`MDRaids.Ground` 按身体大小检查占地和头顶空间（`Room`），所有生成点（夜袭、威胁度袭击、野外、首领护卫、首领自己）都传身体大小。
   - 卡住：`MDUnstuck`（`Mod/MDRobots.cs`），2.5 秒没往前走 0.8 米就跳，再不行就沿墙爬升；会清方块的地面首领陷进坑或沟（脚比周围地面低 1.6 米以上）也爬出来。
   - 开火前检查：从炮口（不是眼睛）到目标的直线，曲射看整条弹道；打不到就不开火、继续走（`ComponentMDRobot.CanHit`、`MDBossState.Shoot`）；
     RD13 加特林按炮口视线，RD19 主炮按主炮炮口，榴弹按弹道，阵地上 3 秒什么都打不到就换位置。
5. 防线核心被摧毁：爆炸（复用塔的重爆炸、游戏爆炸声和机兵毁灭音效；破坏地形跟“机甲火炮、榴弹破坏地形”设置，默认不破坏），
   周围 30 米内的塔断电 180 秒（不开火、不治疗、雷达不加成，头上红字倒计时），放下新核心立即恢复。
6. 机甲导弹冷却：三台机甲一轮齐射后冷却 1.5 秒，HUD 显示“冷却中 x.x 秒”。敌方导弹和导弹塔本来就有间隔，不改。

## 第二批（同日，3 条，同一分支、版本仍是 0.18.0）

User-authorized scope：用户转来的第二批 3 条玩家反馈，“有的问题可能是普遍的，要检查同类并统一修”；追加到 PR #21，不合并、不安装。

1. 声波塔没效果、有的塔要等敌人贴脸才有用（电磁脉冲也是）：先用实验室量所有会攻击的塔对一队正常行进的敌人的实际伤害 / 控制
   （`fb18b-squad1|squad2`），再改。
   - 机兵在自己射程的约 0.6～0.9 处停下开火（双管步行机兵约 14～21 米，战车约 18～27 米），所以射程 9～13 米的声波、电磁脉冲和射程 10～13 米的喷射塔
     几乎碰不到它们。
   - 全向声波塔：新攻击类型 `wave`（`Mod/MDTowerWaves.cs`），朝目标发一道 80° 的扇形波面，每秒 20 格跑到射程尽头，波面扫过的敌人晕眩（同一道波每个敌人一次），
     画出来的波面和判定是同一个半径。
   - 电磁脉冲 Ⅰ–Ⅲ：新攻击类型 `orb`，射出一枚脉冲弹（每秒 22 格），命中处一定半径内瘫痪（`Splash` 加了 `stun`）。
   - 表里另外找到：重锤迫击炮对这队敌人 22 秒 6 发 0 伤害——它总锁在绕圈的无人机上，4～5 秒的高抛弹打不中；改成只打地面（`groundOnly`，和加农炮一样）。
   - 数值：只加射程，晕眩 / 瘫痪秒数、间隔、伤害都没变；没有给任何塔加击退或硬直。
2. 喷射类射程加大：酸洗、毒沼、液氮实际是抛射炮弹（射程 26～30），射程 +4 米、爆炸半径 3 → 3.5，毒沼 / 液氮的残留区跟着加大；真正的喷射塔（激流、熔甲者、
   冰冻 Ⅰ–Ⅲ、火焰 Ⅰ–Ⅲ）射程加到 15～20 米。粒子速度按阻力反算到正好喷到伤害判定的距离（从塔身量，含雷达加成），定向喷射带的判定和范围圈也按雷达加成后的
   射程。机甲没有喷射武器，敌人也没有，不用改。
3. 界面：新的创造物品栏分类“机甲防线”（`Mod/MDCategory.cs`、`Mod/Assets/Lang/zh-CN.json`、`en-US.json`），放全部防御塔、三台机甲和机兵召唤；
   手册“伤害与状态”标签的【】超出按钮：标签按文字宽度定宽，放不下时分两行，过长的标题自动换行。

实验室：`tools/run_isolated.py lab --mode fb18b`（spray / wave / ui / mortar），`fb18b-squad1`、`fb18b-squad2` 单跑。
